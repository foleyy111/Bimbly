BIMBLY WEBSITE

Isi folder:
- index.html : struktur dan konten website
- style.css  : stylesheet tambahan (font, animasi, aturan dasar)
- script.js  : interaksi formulir booking

Cara menjalankan:
1. Simpan ketiga file dalam satu folder.
2. Buka index.html di browser, atau unggah seluruh isi folder ke hosting.
3. Pastikan pengunjung memiliki koneksi internet karena Tailwind CSS dan Google Fonts
   dimuat dari CDN.

Catatan penting:
- Form booking saat ini hanya menampilkan konfirmasi di browser. Form belum mengirim
  data ke database atau admin.
- Tombol WhatsApp menggunakan nomor contoh +62 812-3456-7890. Ganti nomor tersebut
  dengan nomor WhatsApp resmi Bimbly sebelum website dipublikasikan.
- Email dan tautan media sosial juga perlu disesuaikan dengan akun resmi.
